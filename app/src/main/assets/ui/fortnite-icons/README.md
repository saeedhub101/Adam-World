# Fortnite-themed UI image assets

Files in this directory are source image files copied from public GitHub repositories for evaluation and UI integration.

## Sources
- Weapon/item pictograms: https://github.com/dropletzz/ourSpace/tree/main/assets/fortnite
- Fortnite category pictograms: https://github.com/h4lfheart/FortnitePorting/tree/main/src/FortnitePorting/Assets/FN
- V-Bucks and ranked badges: https://github.com/FNLookup/fnlookup.github.io/tree/main/assets

These are not a complete Fortnite Battle Royale HUD pack. The weapon/item pictograms and category graphics are preliminary source assets; verify their visual match before wiring them into the live HUD. No application code was changed by this asset import.
