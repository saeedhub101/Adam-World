# Imported 3D weapon models

All six GLB files in this directory are original Kenney weapon assets, sourced from the public repository:
https://github.com/shorepine/kenney/tree/main/3d/weapon

The upstream repository states that its art assets are released under Creative Commons Zero (CC0 1.0):
https://github.com/shorepine/kenney
https://creativecommons.org/publicdomain/zero/1.0/

Credit: Kenney / https://kenney.nl (appreciated, not required under CC0).

| Adam World file | Upstream file | Intended role |
|---|---|---|
| pistol.glb | pistol.glb | Sidearm |
| assault-rifle.glb | machinegun.glb | Assault rifle |
| submachine-gun.glb | uziLong.glb | SMG |
| shotgun.glb | shotgun.glb | Shotgun |
| sniper-rifle.glb | sniper.glb | Sniper |
| rocket-launcher.glb | rocketlauncherModern.glb | Launcher |

These are imported static GLB meshes. Their visual integration, hand attachment, animation, and firing effects are separate runtime tasks; importing the assets does not by itself complete those systems.
