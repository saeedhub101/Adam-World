# Delivery roadmap

## M0 — Native foundation
- [x] Gradle Android project
- [x] Kotlin + Jetpack Compose application shell
- [x] Initial home screen and navigation shell
- [x] CI debug APK workflow
- [ ] Confirm first CI build and install on a physical device

## M1 — Mapping technical spike
- [ ] Compare MapLibre Native and other viable Android map SDKs
- [ ] Confirm style/tile provider terms and attribution
- [ ] Render an interactive 2D map
- [ ] Add camera controls and location permission flow
- [ ] Verify performance on a mid-range Android device

## M2 — 3D world
- [ ] Select 3D terrain and globe strategy
- [ ] Render terrain with a documented source
- [ ] Integrate 3D Tiles or glTF/GLB building content
- [ ] Implement viewport and level-of-detail loading
- [ ] Add building selection and feature metadata

## M3 — Amman pilot
- [ ] Define a bounded pilot area
- [ ] Validate roads, building footprints, and place names
- [ ] Record source/license/attribution metadata
- [ ] Show source confidence and missing attributes
- [ ] Run geographic alignment and visual QA

## M4 — Product services
- [ ] Search and geocoding
- [ ] Place and building details
- [ ] Saved places and user account
- [ ] Navigation integration
- [ ] Offline region downloads, subject to provider rights

## M5 — Commercial readiness
- [ ] Backend and account security review
- [ ] Subscription design and entitlement enforcement
- [ ] Analytics with privacy controls
- [ ] Accessibility and localization
- [ ] Performance, battery, and crash testing
- [ ] Google Play release preparation
